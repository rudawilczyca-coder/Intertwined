# Original transcripts

This directory preserves source transcripts that materially shaped Intertwined canon.
They are retained in their original wording—including rough prose, superseded details,
and earlier handling of character perspective—so later editing does not erase the
project's creative history.

These files are **source evidence, not automatic line-by-line canon**. The event bibles
remain authoritative for current chronology and outcomes unless Alice and Sable
deliberately promote or revise details.

  Google Doc on August 20, 2026. Preserved verbatim; current canonical summary lives
