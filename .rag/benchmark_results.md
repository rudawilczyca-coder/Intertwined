# Intertwined retrieval benchmark — 2026-08-19

Eight questions taken from live canon work were used to test three properties:

1. an intended canon source appears in the first five results;
2. no single file occupies more than two final result slots;
3. superseded-planning and workflow sources do not enter the final results.

## Before

Captured against the pre-change index and query pipeline.

| Question | Canon source in top 5 | Duplicate-file cap | Excluded sources absent |
|---|---:|---:|---:|
| Tuesday / no Tuesday | no | yes | yes |
| Eli cover | yes | yes | yes |
| Theo's walks | yes | no | yes |
| Paris hotel | yes | yes | yes |
| Green Park | no | yes | no |
| Children | yes | yes | yes |
| Apology letter | yes | yes | yes |
| Camarilla guns | yes | yes | no |

**All three conditions passed: 4/8.** The most visible failures were four
chunks from the Primrose Hill handoff crowding the walks query, superseded
Green Park planning entering results while Book Nine did not, and a workflow
example entering the Camarilla query.

## After

Generated by `.rag/benchmark.py --rerank on` after rebuilding the index.
Two consecutive runs produced the same table.

| Question | Canon source in top 5 | Duplicate-file cap | Excluded sources absent |
|---|---:|---:|---:|
| Tuesday / no Tuesday | yes | yes | yes |
| Eli cover | yes | yes | yes |
| Theo's walks | yes | yes | yes |
| Paris hotel | yes | yes | yes |
| Green Park | yes | yes | yes |
| Children | yes | yes | yes |
| Apology letter | yes | yes | yes |
| Camarilla guns | yes | yes | yes |

**All three conditions passed: 8/8.**

The rebuilt corpus contains no chunks from `archive/superseded-planning/`,
`workflows/`, or files named with the `_template.md` convention. Voyage now
receives source path, heading, and file title with each candidate. Final
selection caps a file at two chunks and suppresses copied or lightly edited
prose echoes using five-word-shingle containment.
