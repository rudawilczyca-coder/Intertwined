# Height-chart cutouts

Transparent, tightly cropped full-body PNGs for constructing an exact manual
height comparison. Resize the visible figures to the desired pixel heights and
align the soles on one shared baseline.

Using Theodore at 1000 px:

- Theodore — 1000 px (185.4 cm / 6'1")
- Draco — 973 px (180.3 cm / 5'11")
- Jackie — 877 px (162.6 cm / 5'4")
- Nell — 849 px (157.5 cm / 5'2")

The imperial heights are canon. Metric values are their exact conversions,
rounded to one decimal place; pixel ratios are rounded to the nearest pixel.

The images deliberately carry no scale relationship of their own. Their tight
transparent crops are intended to be resized independently.

Source render: GPT Image 2, using the approved Nell height-chart pass as the
identity and style reference. Flat chroma-key background removed locally; alpha
edges and transparent corners verified before filing.
